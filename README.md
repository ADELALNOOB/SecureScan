# SecureScan

SecureScan is an enumeration and scanning platform for penetration testing, inspired by TireFire and powered by HackTricks.

## Features
- Semi-automatic scans controlled by the user
- Detailed reports of all scans performed
- Integration with popular tools like nmap, ffuf, and more
